## 📖 项目简介
「雪影」是由 **雪影极客实验室 (Snow-Shadow Geek Lab)** 开发的滑雪垂直领域 AI 综合解决方案。针对当前滑雪市场教练水平透明度低、装备推荐商业化严重的痛点，利用小米 MiMo V2.5 大模型的多模态能力，构建行业首个 AI 视觉审计与智能决策系统。

## 🚀 核心功能模块
* AI 灵影 (Visual Audit): 基于视频流的 24 关键点骨架分析，量化评估入弯角度、稳定性及立刃效果。
* 雪影测算 (Ski-Gear AI): 针对不同体能与技术等级的垂直领域语义搜索与匹配。
* 清雪行动 (Clean-Snow): 基于 AI 仲裁的师生双向权益保护与信用存证。
